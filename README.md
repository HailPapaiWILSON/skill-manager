# Skill Manager

Plataforma fullstack para visualização, organização e análise de competências técnicas em equipes de tecnologia.

O Skill Manager funciona como um mapa técnico organizacional, permitindo identificar a distribuição de conhecimento, especialistas e dependências críticas dentro da empresa.

## Funcionalidades Principais

- Gestão de Habilidades: Mapeamento de skills individuais e níveis de domínio.
- Análise de Equipes: Visualização de gaps técnicos e distribuição de competências por time.
- Dashboards Analíticos: Heatmaps e métricas sobre tecnologias mais utilizadas e riscos técnicos.
- Mapeamento de Projetos: Relacionamento entre tecnologias, equipes e especialistas.

Para detalhes completos das funcionalidades, veja [features.md](./features.md).

## Tecnologias

- Frontend: React
- Backend: Node.js (API REST), Sqlite.

## Arquitetura e Decisões

O projeto foi desenhado com foco em analytics técnicos, evitando complexidades de RH e focando puramente em competências de engenharia.

Saiba mais sobre a evolução e decisões técnicas em [architecture.md](./architecture.md)
