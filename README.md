# Skill Manager

Plataforma full stack para visualização, organização e análise de competências técnicas em equipes de tecnologia.

O Skill Manager funciona como um mapa técnico organizacional, permitindo identificar a distribuição de conhecimento, especialistas e dependências críticas dentro da empresa.

## Funcionalidades Principais

- **Gestão de Habilidades:** Mapeamento de habilidades individuais e níveis de domínio.
- **Análise de Equipes:** Visualização de lacunas técnicas e distribuição de competências por equipe.
- **Dashboards Analíticos:** Heatmaps e métricas sobre as tecnologias mais utilizadas e os riscos técnicos.
- **Mapeamento de Projetos:** Relacionamento entre tecnologias, equipes e especialistas.

Para mais detalhes sobre as funcionalidades, consulte [features.md](./docs/features.md).

## Tecnologias

- **Frontend:** React
- **Backend:** Node.js (API REST) e SQLite.

## Arquitetura e Decisões

O projeto foi desenvolvido com foco em análises técnicas, evitando complexidades relacionadas à gestão de RH e concentrando-se exclusivamente nas competências de engenharia.

Saiba mais sobre a evolução do projeto e as decisões técnicas em [architecture.md](./docs/architecture.md).

## Instalação

Este projeto não possui um processo de instalação independente. Para executá-lo localmente, é necessário utilizá-lo em conjunto com o repositório [skill-manager-frontend](https://github.com/HailPapaiWILSON/skill-manager-skill-frontend).

As instruções para executar o projeto estão disponíveis em [installation.md](./docs/installation.md).
